# Contributing

Thanks for looking, but this repository does not accept contributions.

It contains **generated output**, not source. The HTML here is built from a
private repository and force-pushed to the `gh-pages` branch on every build.
A change committed here would be destroyed by the next build and would never
reach the source it was generated from, so there is nothing a pull request
could usefully fix.

Pull requests opened against this repository are closed automatically.
